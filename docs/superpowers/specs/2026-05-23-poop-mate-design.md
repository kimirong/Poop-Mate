# 拉屎宝 - 移动端打卡应用设计

**日期：** 2026-05-23
**版本：** v1.0

---

## 1. 产品定位

一款极简有趣的如厕打卡工具，通过游戏化（积分/排行榜）增加用户粘性，适合在厕所场景自然传播。

**使用场景：** 用户在蹲坑时发现二维码，扫码进入页面进行打卡。

---

## 2. 核心功能

### 2.1 登录与 Token 机制
- 基于 Supabase 的云端身份识别 + 自定义 Token 方案
- users 表新增 `login_token` 字段，存储登录凭证
- 登录时生成随机 Token，存入浏览器 localStorage，永不过期
- 每次进入页面自动携带 Token 验证身份

**登录流程：**
1. 用户输入昵称 → 查询 Supabase users 表
2. 存在 → 生成随机 Token → 更新该用户的 login_token 字段 → 存入 localStorage → 进入打卡页
3. 不存在 → 友好提示"昵称不存在，请重新输入"

**Token 自动登录：**
1. 进入页面 → 检查 localStorage.login_token
2. 存在 → 验证 Token 有效 → 直接进入打卡页
3. 无效/不存在 → 显示登录页

**Supabase 表结构：**
- `users`：id, nickname, created_at
- `check_ins`：id, user_id, timestamp, mood, created_at

### 2.2 打卡功能
- **圆形打卡按钮**：120px 直径，渐变粉色，马桶图标
- **心情输入框**：多行文本，始终显示在打卡页，非必填，max 200 字符
- 打卡时记录：时间戳 + 心情内容

### 2.3 打卡成功反馈
- 打卡成功弹层
- 显示"今日第 X 次"
- 排行榜入口按钮

### 2.4 排行榜
- 三种排名维度：总次数 / 今日 / 连续天数
- Tab 切换展示
- 当前用户高亮显示

## 3. 页面结构

**页面数量：** 2 个

| 页面 | 路由 | 说明 |
|------|------|------|
| 登录页 | / | 昵称输入登录，查询用户是否已注册 |
| 打卡页 | /home | 主页面，含打卡按钮、心情输入、排行榜入口 |
| 排行榜页 | /leaderboard | 完整排行榜展示 |

**跳转逻辑：**
```
进入页面
    ↓
检查 localStorage.login_token
    ↓
存在？→ 验证 Token → 有效 → 打卡页
    ↓ 不存在/无效
显示登录页（昵称输入）
    ↓
用户输入昵称 → 查询 Supabase users 表
    ↓
存在？→ 生成 Token → 存入 localStorage → 打卡页
不存在？→ 友好提示"昵称不存在，请重新输入"
```

## 6. 数据存储（Supabase）

### 6.1 数据库表结构

**users 表：**
| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| nickname | varchar(10) | 昵称，唯一 |
| login_token | varchar(64) | 登录凭证 |
| created_at | timestamp | 创建时间 |

**check_ins 表：**
| 字段 | 类型 | 说明 |
|------|------|------|
| id | uuid | 主键 |
| user_id | uuid | 外键关联 users |
| timestamp | timestamp | 打卡时间 |
| mood | varchar(200) | 心情内容 |
| created_at | timestamp | 创建时间 |

### 6.2 localStorage 结构
```javascript
{
  login_token: "用户登录凭证，永不过期"
}
```

### 6.3 Token 验证流程
1. 页面加载时读取 localStorage.login_token
2. 查询 Supabase users 表，WHERE login_token = token
3. 找到则自动登录，找不到则显示登录页

### 6.4 打卡时序
1. 点击打卡 → 获取当前时间戳
2. 读取心情输入框内容
3. 写入 Supabase check_ins 表
4. 弹出打卡成功卡
5. 更新今日次数显示

## 8. 技术实现

- **前端框架：** Next.js（App Router）
- **UI 组件库：** Vant UI（移动端组件库）
- **样式：** Tailwind CSS
- **后端：** Supabase（PostgreSQL + Realtime）
- **路由：** Next.js 文件路由（/、/home、/leaderboard）
- **动画：** CSS transitions + keyframes

### 8.1 Supabase 配置
- 项目 URL 和 anon key 配置在 .env.local
- RLS (Row Level Security) 策略控制数据访问

### 8.2 项目目录结构
```
/app
  /page.tsx           # 登录页
  /home/page.tsx      # 打卡页
  /leaderboard/page.tsx # 排行榜页
  /layout.tsx         # 根布局
/components
  /CheckInButton.tsx   # 圆形打卡按钮
  /MoodInput.tsx      # 心情输入框
  /SuccessModal.tsx   # 打卡成功弹层
  /Leaderboard.tsx    # 排行榜组件
  /NicknameForm.tsx   # 昵称登录表单
/lib
  /supabase.ts        # Supabase 客户端
  /auth.ts            # Token 验证逻辑
/styles
  /globals.css        # 全局样式 + Tailwind
```
